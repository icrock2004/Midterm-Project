The goal of this project is to create CNN and RNN (LSTM) models and see if we can classify which LLM wrote a certain response. 
This will be accomplished by gathering the data, training the model and fine-tuning the parameters for the model, then testing multiple situations 
such as input only, output only, and input + output and comparing how the classifiers perform and how accurately they are able to make these classifications.

NOTE: The midterm_proj.ipynb file contains the full code and outputs, the classification.py file only includes the code needed for the first research question.
